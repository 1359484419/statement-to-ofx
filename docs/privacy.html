Privacy

Bank statements are some of the most sensitive files you have. This converter is built so that they never leave your device.

What happens to your file

  • Your browser reads the file you choose. The CSV, spreadsheet or PDF is parsed by JavaScript running in this tab, using libraries served from this site (PDF.js for PDFs, SheetJS for spreadsheets).
  • The output file is built in memory and handed to your browser as a download.
  • Nothing is sent to a server. There is no server-side code at all: the site is static files.
  • When you close the tab, the statement is gone.

What the page stores

Only your export preferences (account type, account number, bank ID, currency, INTU.BID and Xero date format) are kept in your browser's local storage so you do not have to type them again. Clear your site data to remove them. Transactions are never stored.

No tracking

No analytics, advertising, fonts or scripts are loaded from other domains. The pages send a Content-Security-Policy that limits scripts and network connections to this site, and the converter also blocks any attempt to contact another origin and records it in the activity log.

Check it yourself

  1. Open the converter and your browser's developer tools (F12, or Cmd+Option+I on a Mac).
  2. Go to the Network tab and clear it.
  3. Drop a statement and export a file.
  4. You will see requests only for this site's own scripts (for example pdf.worker.min.mjs the first time you open a PDF) and no request carrying your file. You can also disconnect from the internet after the page loads; conversion keeps working.

The source code is MIT licensed and can be run from a local folder.

Hosting

The site is served as static files by its hosting provider, which, like any web host, may keep standard access logs (IP address, page requested, time). Those logs never contain your statement.
